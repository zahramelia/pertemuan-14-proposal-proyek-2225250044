# Program Rekap dan Analisis Nilai Matematika Kelas

## Deskripsi Proyek

Program Rekap dan Analisis Nilai Matematika Kelas merupakan program berbasis Python yang dirancang untuk membantu guru mengolah dan menganalisis nilai siswa secara sederhana.

Program ini dapat membaca data nilai dari file teks, memvalidasi nilai dalam rentang 0–100, menghitung rata-rata, nilai tertinggi, nilai terendah, serta menentukan jumlah siswa yang tuntas dan belum tuntas berdasarkan Kriteria Ketuntasan Minimal (KKM).

## Tujuan

1. Mempermudah pengolahan data nilai matematika.
2. Menghitung statistik nilai secara otomatis.
3. Menentukan ketuntasan berdasarkan KKM.
4. Menghasilkan laporan rekap nilai dalam file teks.

## Fitur Utama

- Membaca data nilai dari file.
- Memvalidasi nilai antara 0–100.
- Menghitung rata-rata, nilai tertinggi, dan nilai terendah.
- Menghitung jumlah nilai tuntas dan belum tuntas.
- Menyimpan hasil analisis ke file laporan teks.

## Teknologi

- Bahasa pemrograman Python 3.
- Visual Studio Code.
- Git dan GitHub.

## Struktur Proyek

- `data/`: menyimpan data nilai contoh.
- `src/`: menyimpan kode program Python.
- `tests/`: menyimpan dokumentasi test case.
- `output/`: menyimpan laporan hasil program.
- `proposal.md`: berisi rancangan proyek.
- `README.md`: berisi informasi proyek.
